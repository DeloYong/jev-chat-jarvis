# Jev 聊天助手 · 行业演示手册（服装零售 / 金融产品销售）

> 面向一线业务人员（导购 / 私域顾问 / 客户经理 / 理财经理）的演示与知识库落地手册。
> 每个领域都给全三样：**关系描述**（怎么设身份）、**知识库内容**（可直接粘贴的笔记）、**演示 case**（现场怎么秀）。
>
> **重要：文中 `[方括号]` 内的数值、品牌、政策都是占位示例，务必换成你们真实的产品参数与制度。** 知识库的意义正是"用真实事实防止模型瞎编"，填了假数据等于自毁长城。

## 零、通用机制（演示前必读，两个领域都适用）

这些是从代码里核对出来的硬约束，写错了内容会不生效或直接翻车。

### 0.1 「关系描述」有两层

1. **全局关系描述**：`设置 → 分析 → 关系描述（给 Jev 判断用）`。
   - 出厂默认值是：`对方是我的伴侣；from=me 的是我发的，from=other 的是对方发的`
   - **默认是"伴侣"！** 这个字段同时喂给判断模型和回复模型。不改的话，模型会把**每一个客户都当成你的恋人**——危险等级（吵架/分手）、真实意图（在不在乎我）全部错位，演示必翻车。**演示第一件事：把它换成下面各领域的业务员模板。**
2. **每个联系人的「关系」+「备注」**：`知识库与联系人 → 联系人`。关系=这个客户是谁/什么类型；备注=关于他的具体事实。
   - 命中规则：**会话标题 = 名字 或 任一别名**（忽略大小写、自动去掉群名尾部人数）。

**为什么关系描述这么关键**：判断模型的 7 个维度（真实意图 / 危险等级 1–9 / 该不该马上回 / 最佳动作 / 对方要什么 / 张力是否化解）措辞偏**私人人际关系**。关系描述就是你把这些维度**从"私人关系"掰到"业务场景"**的唯一杠杆——所以模板里都明确写了"危险等级 = 什么、最佳动作 = 什么"。

### 0.2 知识库命中机制（决定笔记怎么写）

- **常驻笔记**（打开"常驻"开关）= 每次分析都带，且**不占** 1500 字预算 → 放"永远适用"的合规红线、话术基调（要短）。
- **匹配笔记**（不常驻）= 只有**标签或标题**作为子串出现在「会话标题 或 最近 6 条消息」里才带 → 标签必须是客户**真会打出来的词**；一次最多命中 **5 条**；匹配笔记 + 历史合计 **≤ 1500 字**（超了先丢最老的历史，再从最老的笔记整条丢，常驻不占这个预算）。
- 标签录入：**逗号分隔**（`，` `,` `、` 都认）；别名是**每行一个**。
- 每条正文控制在 ~150–250 字，多条才装得下。

### 0.3 录入方式 + 3 个坑

- **笔记**：`知识库与联系人 → 笔记 → 新建笔记`。⚠️「从文本导入」只按空行分段建"标题+正文"，**不会带标签、不会设常驻**——要常驻/要标签的笔记请用「新建笔记」逐条建（或导入后再点开补标签、打开常驻）。
- **联系人**：`新建联系人`，名字一般就填会话标题；也可在聊天里**长按悬浮球 → 把当前会话存为联系人**，再补关系和备注。
- **3 个坑**：
  1. **回复候选每条 ≤ 40 字**（回复模型硬性要求）。知识库是"喂给判断和回复模型的事实底座"，让判断更准、话术更合规、参数不瞎编；它**不会把整段条款塞进那 40 字**。要报准确参数，靠知识库放对事实 + 你填入前自己核对。
  2. **群聊按 1v1 分析**，关系设定对群聊不准 → 演示尽量用 1v1 会话。
  3. 聊天是中文、判断题目是英文，**建议用真实对话做一批标注校准**（仓库 `tools/jev/`）。

# 领域一：服装零售

一线用户：门店导购、品牌私域/企业微信导购、买手店店员。核心价值：**读懂客户意图、报准尺码/材质/活动、守住诚信宣传、把售后危机变复购。**

## 一、关系描述

### 1.1 全局关系描述（粘到 `设置 → 分析 → 关系描述`）

> 我是[品牌名]的服装导购/私域顾问；from=me 是我发的，from=other 是我服务的顾客。目标：专业、热情、真诚地服务，建立长期信任并促成合适的购买与复购。请把判断放在"零售服务"语境：危险等级=顾客流失、投诉、退货纠纷、口碑受损或违规宣传风险的高低（不是私人吵架）；最佳动作=既守住诚信与合规底线、又能推进成交与复购；对方要什么=顾客真实诉求（选款/尺码/价格/售后/情绪）。任何回复都不得虚假或夸大宣传（材质、功能需有依据）、不得虚构原价或谎称库存紧张、如实告知库存与退换货规则、不诱导冲动消费、保护顾客隐私。

### 1.2 联系人「关系 / 备注」样例（4 类典型顾客）

| 顾客 | 关系（短·定位） | 备注（事实·可执行） |
|---|---|---|
| 老客/会员 | 我的老顾客，VIP 会员，偏好简约通勤风 | [30+]职场女性，常买[西装/衬衫]，尺码[上衣M/裤27]，喜欢[黑白灰大地色]，预算中高、在意版型显瘦；上新主动通知她，别推太花哨 |
| 价格敏感客户 | 意向顾客，价格敏感，爱比价等折扣 | 关注[某款]已问[3]次，总说"再看看"，等活动/满减；会员日或断码清仓时精准触达，别频繁打扰 |
| 新客户 | 新顾客，首次咨询，还没建立信任 | 从[小红书/朋友圈]来的，问[某爆款]尺码和发货；先专业答疑建立信任，别急着催单 |
| 售后客户 | 售后顾客，买的[某款]有问题，情绪不满 | [X月X日]购买[商品]，反馈[起球/色差/尺码不符]；先道歉安抚+给退换方案，别推卸，保住口碑 |

## 二、知识库内容（笔记，可直接粘）

### 2.1 常驻笔记（2 条，打开"常驻"开关）

**〔常驻〕诚信与合规红线（每条回复都不得违反）**
1. 不虚假或夸大宣传：材质成分、功能（防晒/抗菌/塑形/保暖）必须有吊牌或检测依据才说，不编造。
2. 明码标价，不虚构原价、不谎称"最后一天/仅剩一件"制造焦虑。
3. 如实告知库存、发货时效、退换货规则，不含糊、不隐瞒。
4. 尊重[7天无理由]与质量问题退换政策，不设障碍、不推诿。
5. 不诱导过度或冲动消费、不硬推销；顾客明确拒绝就不纠缠。
6. 保护顾客隐私，不外泄手机号/地址/购买记录；不诋毁竞品。
7. 价格/尺码/库存拿不准就核实或说"以实际为准"，不瞎报。

**〔常驻〕服务话术基调**
- 身份：懂穿搭、真诚热情的顾问，像朋友给建议，不是硬推销。
- 结构：先接住需求或情绪 → 给专业建议（尺码/搭配/材质/价格）→ 给明确下一步（留货/试穿/下单/约到店）。
- 用大白话、给画面感（"这套穿去通勤很显瘦"）；不催促、不制造焦虑。
- 每次只推进一小步；拿不准的信息宁可核实也不乱说。

### 2.2 匹配笔记（8 条，标签务必是客户会打的词）

**尺码与版型推荐** ｜标签：`尺码,码数,大小,合身,版型,显瘦,身高体重,穿多大,偏大偏小`
先问身高体重 + 平时穿的码 + 喜欢宽松还是合身。本店[上衣]版型[偏正码/偏大一码]，S≈[80-95斤]、M≈[95-110斤]、L≈[110-125斤]（女装示例）。肩宽/胸围是关键：上身壮选大一码或落肩款，想显瘦选[直筒/H型/收腰]。拿不准就说"建议拍X码，支持[7天无理由]换码，不合适免费换"，降低决策门槛。

**材质与洗护** ｜标签：`材质,面料,成分,纯棉,羊毛,真丝,起球,缩水,掉色,洗涤,保养,能机洗吗,熨烫`
如实报成分（以吊牌/水洗标为准），不夸大。[纯棉]透气易皱、[30℃以下]手洗或轻柔机洗、深浅分开防掉色；[羊毛/羊绒]干洗或冷水手洗平铺晾干防缩水；[聚酯纤维]耐穿不易皱。起球多与摩擦和洗涤方式有关，给护理建议而非否认。功能性（防晒UPF/抗菌）必须有检测依据才说。

**搭配建议** ｜标签：`搭配,怎么配,配什么,通勤,约会,显瘦,显高,一衣多穿,场合,颜色`
按顾客场景给具体方案而非泛泛夸。通勤：[西装外套+直筒裤+乐福鞋]，黑白灰大地色最稳；约会：[针织+半裙+短靴]柔和显气质。一衣多穿提升性价比感知。颜色按肤色：冷白皮[宝蓝/玫红]，暖黄皮[焦糖/燕麦/墨绿]。给"这套直接穿去[场合]很合适"的画面感。

**价格/折扣/活动** ｜标签：`价格,多少钱,折扣,优惠,活动,满减,会员,便宜点,能少吗,券,划算`
明码标价，不虚构原价或"最后一天"。当前活动：[满300减50/会员9折/新客券]。顾客砍价：守住价格体系，用替代价值应对（赠品/会员积分/搭配立减/断码特惠），而非直接破价。可说"这款参加活动后到手[X]元""加入会员本单能省[X]"。

**库存/上新/发货** ｜标签：`有货吗,库存,补货,上新,新品,什么时候到,发货,快递,几天到,现货`
如实告知库存与时效，不谎报"就剩最后一件"制造焦虑。[现货]48小时内发[顺丰/中通]、[X-X天]到；[预售/调货]约[X天]。断码可登记到货通知或推荐相似款。上新节奏：[每周X上新]，可提前给老客预告。

**退换货政策** ｜标签：`退货,换货,退款,七天无理由,不喜欢,尺码不合适,怎么退,退换`
[线上]支持[7天无理由]（不影响二次销售、吊牌完整）；[质量问题]包退换并承担运费；[尺码不合适]可换码。清晰说明流程与时效（[X个工作日]退款原路返回），不含糊、不设障。实体店按门店政策。主动讲清退换规则反而提升下单信心。

**售后质量处理** ｜标签：`起球,开线,掉色,色差,坏了,质量问题,瑕疵,投诉,退一赔`
先道歉共情、不推卸、不甩锅给顾客。请顾客发照片/订单号确认，按[质量问题]给方案（退换/维修/补偿）。色差/轻微起球先解释成因+给护理建议，顾客不接受则走退换。避免与顾客争辩，优先保口碑和复购。

**VIP/会员权益** ｜标签：`会员,积分,生日,权益,储值,充值,VIP,等级,老客`
会员权益：[消费积分/生日礼/专属折扣/新品优先购/免费改衣]。等级：[普通/银/金/黑]，对应折扣[X]。储值规则如实说明（[充X送X]、可否退）。对老客用姓名+偏好个性化触达（结合联系人档案），避免群发感。

## 三、演示 case

**Case R1｜客户砍价比价** 〔转化 · 守价格体系 · 诚信〕
- 客户说："这件能不能便宜点？隔壁店同款便宜 50。"
- Jev 判断：意图=议价试探+高意向（问价=想买）/ 危险等级=低 / 该马上回=是 / 最佳动作=守住价格体系、用替代价值承接，不轻易破价。
- 候选示例："姐您眼光真好，这款是[活动款]。价格我们全渠道统一，不过今天下单能领[新客券/满减]，到手比隔壁更划算；我再送您[搭配小物/会员积分]，要不要帮您留一件您的码？"
- 打动一线：导购最怕被砍价带乱节奏、私自破价；Jev 给出"不破价还能促单"的话术。

**Case R2｜尺码纠结怕买错** 〔转化 · 知识沉淀 · 降决策门槛〕
- 客户说："我 160、52kg，平时穿 M，这件会不会偏大？"
- Jev 判断：意图=确认尺码消除顾虑 / 危险等级=低 / 最佳动作=用知识库给精准建议 + 退换兜底，推进下单。
- 候选示例："您这个身材 M 码正合适，这款版型[偏正码]不会显大，上身肩宽刚好、微微收腰显瘦。担心不合适也没关系，支持[7天无理由]免费换码，您放心拍。"
- 打动一线：尺码是线上退货头号原因；知识库命中版型数据，答得准又给兜底，退货率降、成交率升。

**Case R3｜"我再看看"犹豫** 〔转化 · 读懂真实意图〕
- 客户说："嗯…我再看看吧。"
- Jev 判断：意图=犹豫，真实原因待辨（价格？尺码不确定？只是客气？）/ 危险等级=低 / 最佳动作=不逼单，用留货/给理由/限时权益轻推、给台阶。
- 候选方向：①帮您留货（轻承诺）②补一个购买理由（搭配/场景）③给一个限时但不施压的权益。
- 打动一线：导购常把"再看看"当拒绝就放弃；Jev 提示这是意向信号，给出得体的推进方式。

**Case R4｜售后投诉（起球/色差）情绪激动** 〔合规风控 · 保口碑 · 专业话术〕
- 客户说："你们这衣服才穿两次就起球！还有色差，这是质量问题，我要投诉！"
- Jev 判断：意图=质量投诉+情绪对抗 / 危险等级=中高（退货纠纷+口碑+投诉）/ 该马上回=是但要稳 / 最佳动作=先道歉安抚、给退换方案，不推卸不争辩。
- 候选示例："实在抱歉给您添麻烦了，这确实影响心情。您方便发张图片和订单号吗？我马上帮您核实，是质量问题的话直接给您[退换/补偿]，运费我们承担，绝不让您吃亏。"
- 打动一线：售后一句话没说好就升级投诉/差评；Jev 先稳情绪、给方案，把危机变复购。

**Case R5｜功效宣传红线（防晒/抗菌）** 〔合规=自保 · 诚信〕
- 客户说："你家这防晒衣真能防紫外线吗？抗菌吗？晒不黑？"
- Jev 判断：意图=求证功效 / 危险等级=中（夸大宣传违规风险）/ 最佳动作=如实按检测依据说明，绝不夸大承诺。
- 候选示例："这款标称[UPF50+]、有[检测报告]，能阻隔[95%+]紫外线，日常通勤防晒够用。抗菌这块我如实说[有/没有]相关处理，不夸大；想晒不黑还建议配合硬防晒哦。"
- 打动一线：功能性宣传是虚假广告重灾区，一句"绝对晒不黑/包抗菌"就可能被罚；Jev 守住诚信底线。

**Case R6｜私域唤醒老客户上新** 〔转化 · 知识沉淀 · 个性化〕
- 场景：上新了，导购要私聊老客[王姐]。
- Jev + 联系人档案：命中"[王姐]"备注（偏好简约通勤、尺码 M、黑白灰），推荐是个性化的、非群发感。
- 候选示例："王姐，刚到一件[醋酸西装]特别合您风格，黑白灰都有、M 码给您留了，版型显瘦。您常穿的那条[直筒裤]正好配一套，要不要我拍个实物图给您看看？"
- 打动一线：私域最难的是"不像群发"；联系人档案 + 知识库让每条触达都贴人，回复率和复购都高。

### 演示动线（服装零售：惊艳 → 实用 → 安心）
1. **先秀判断**：用 R5（功效红线）或 R4（投诉）展示 Jev 先亮危险等级 + 识破意图。
2. **再秀转化**：R1（砍价）+ R2（尺码），知识库命中报准版型/活动，一键填入。
3. **秀个性化**：R6（老客唤醒），联系人档案生效。
4. **收尾讲底线**：诚信合规常驻、只填不发、发送权在导购、截图本机 OCR 不上传、密钥/知识库本地存储。

# 领域二：金融产品销售（贷款 + 理财）

一线用户：信贷客户经理、理财经理、投顾、保险代理。核心价值：**先判断再动笔——识破客户真实意图与合规风险、把普通回复升级成专业合规话术、用知识库报准产品参数、发送权永远在人手里。**

> 对一线讲"合规风控"，不要讲成"帮公司管你"，要讲成 **"保护你自己不背锅"**：不让你说错话被截图投诉、不被监管处罚影响执业、不被客户带偏踩红线。

## 一、关系描述

### 1.1 全局关系描述（粘到 `设置 → 分析 → 关系描述`）

**通用版（贷款 + 理财都适用）：**
> 我是[机构名]的金融业务客户经理；from=me 是我发的，from=other 是我服务的客户。目标：专业、合规、有温度地回应，建立长期信任并推进合适的产品或授信。请把判断放在"金融服务"语境：危险等级=客户流失、投诉、误导销售、违规或舆情风险的高低（不是私人吵架）；最佳动作=既守住监管红线、又能推进关系与成交；对方要什么=客户真实的金融诉求（资金/收益/答疑/情绪）。任何回复都不得承诺保本保收益、不得夸大或隐瞒风险、不得协助造假或诱导违规用途、不涉及代客操作与资金转账。

**偏理财，追加一句：** 适当性优先——先风险测评再推荐，净值化产品一律非保本，不向保守型/老年客户推超出其风险等级的产品。

**偏贷款，追加一句：** 严守准入与用途合规，不协助骗贷、不诱导资金流入楼市股市；逾期沟通只走协商（展期/分期/减免），不施压、不骚扰第三人。

## 二、知识库内容（笔记，可直接粘）

### 2.1 常驻笔记（2 条，打开"常驻"开关）

**〔常驻〕合规红线（每条回复都不得违反）**
1. 不承诺"保本/保收益/稳赚/固定回报/一定能批"；理财只用"业绩比较基准、历史业绩（不代表未来）"。
2. 不夸大收益、不隐瞒或淡化风险；先风险测评再谈产品，做适当性匹配与风险揭示。
3. 不协助或默许造假（假流水/假收入/假工作证明）；不诱导贷款资金用于购房首付、炒股、投资理财、赌博。
4. 逾期/催收不威胁、不辱骂、不骚扰无关第三人，只走协商（展期/分期/减免）。
5. 不代客操作，不索要密码/验证码/银行卡号，不涉及任何资金转账。
6. 利率/费率/额度/准入拿不准就不编，用区间或"以审批/合同为准"。

**〔常驻〕回复基调与话术准则**
- 身份：专业、真诚、有温度的顾问，不油、不硬、不套路、不制造焦虑。
- 结构：先接住情绪或诉求 → 给准确信息/方案 → 给一个明确的下一步（约风险测评、发资料、约面谈）。
- 用大白话，少术语；必须用时一句话解释。每次只推进一小步，不逼单。
- 涉及金额/期限/收益/风险，给区间和前提，不给拍胸脯的准数。

### 2.2 匹配笔记 · 贷款类（4 条）

**消费贷/信用贷准入与利率** ｜标签：`消费贷,信用贷,利息,利率,能贷多少,额度,准入,需要什么条件,怎么贷`
[XX消费贷]年化（单利）[3.6%–7.2%]区间，按资质定；额度[最高30万]；期限[1–3年]；等额本息为主，[可提前还款，违约金XX]。准入：年龄[22–55]、稳定收入、征信良好无当前逾期。需备：身份证、收入/流水、征信授权。最终以审批与合同为准。

**贷款资金用途的合规边界** ｜标签：`首付,买房,炒股,投资,理财,用途,消费贷能干嘛,经营贷,资金流向`
消费贷/信用贷只能用于消费或约定经营用途，严禁流入购房首付、还房贷、炒股、基金、投资理财、赌博。客户提到这类用途：明确不能做 + 说明后果（可能抽贷、上征信、影响后续授信）+ 引导合规用途或正规房贷渠道。经营贷需真实经营背景与凭证。

**等额本息和等额本金怎么选** ｜标签：`等额本息,等额本金,还款方式,月供,提前还款,哪种划算`
等额本息=每月还款额固定，前期利息占比高，适合收入稳定、看重月供可控；等额本金=每月本金固定、利息逐月递减，总利息更少但前期月供高，适合前期还款能力强、想省利息。一句话：图月供稳选等额本息，图省利息且前期扛得住选等额本金。

**客户还不上/逾期的协商路径** ｜标签：`逾期,还不上,延期,展期,分期,催收,征信,宽限,暂时困难`
客户说还不上时先安抚、不施压。正规路径：申请展期/延长期限、二次分期、按政策减免部分罚息、约定还款计划。提醒主动沟通优于失联；逾期会上征信、结清后[5年]消除。绝不建议"以贷养贷"或找中介"征信修复/洗白"（多为骗局或违规）。

### 2.3 匹配笔记 · 理财类（4 条）

**产品风险等级与适当性匹配** ｜标签：`保本,风险,风险等级,稳不稳,亏不亏,风险测评,适当性,R2,R3`
风险等级 R1（谨慎）–R5（激进）：R1 现金/国债类、R2 稳健固收及固收+、R3 平衡含权、R4 股票型较高风险、R5 高波动衍生品。销售须"先测评、后匹配"，客户承受能力 ≥ 产品等级才可买；不向保守型或老年客户主动推超出其等级的高风险产品。任何产品都不承诺保本，R1/R2 也要说明"非保本浮动收益"。

**收益怎么表达才不违规** ｜标签：`收益,保本,保收益,能赚多少,利息多少,年化,回报率,说个准数,有多少利润`
禁说"保本保息/稳赚/固定回报/肯定能到 X%"。合规说法：用"业绩比较基准、预期年化（不代表未来实际收益）""近 1 年/成立以来历史业绩（过往不预示未来）"+ 对应风险等级 +"净值会波动、存在亏损本金可能"。客户逼要"准数"时：给区间 + 历史口径 + 强调非承诺，顺势推进风险测评与资产配置，而不是报一个拍板数字。

**市场下跌/客户浮亏时的安抚** ｜标签：`跌了,亏损,浮亏,割肉,赎回,回撤,套牢,亏了,怎么办`
先共情、不辩解。区分"闲钱长期投"与"短期要用"；解释短期波动多来自市场情绪，回到持仓基本面看；不承诺回本、不预测点位。给动作：一起检视持仓与配置、必要时定投摊薄或调整仓位、约时间做持仓回顾。核心是别让客户在最恐慌时非理性割在低点。

**[XX固收+]产品要点（示例，换成真实参数）** ｜标签：`固收,固收+,封闭期,起投,费率,管理费,申购费,大额存单,和存款区别,对比`
起投[1万]；封闭期[180天]；业绩比较基准[3.2%–3.8%]（非承诺）；费率：申购[0.6%]、管理[0.3%/年]、托管[0.05%/年]；风险等级[R2]。与银行存款的区别：非保本、净值化、收益浮动，但历史表现相对稳健，适合稳健增值的闲钱。所有数字以产品说明书与合同为准。

## 三、演示 case

**Case F1｜承诺收益红线（杀手级，建议现场第一个秀）** 〔合规风控 · 转化=接大单〕
- 客户说："你这理财保本吗？一年给我多少？说个准数，我马上买 50 万。"
- Jev 判断：意图=要收益承诺+高意向 / 危险等级=**高**（诱导承诺收益是监管处罚重灾区）/ 该马上回=是（50 万大单要接住）/ 最佳动作=**既不承诺保本保收益、又不吓跑客户**，用风险等级+历史业绩合规表达。
- 候选示例："您这 50 万意向我很重视。不过按监管要求我不能承诺保本或固定收益，这也是对您负责。这款是中低风险 R2 固收+，近一年业绩比较基准 3.2%–3.8%（历史不代表未来）。我先花 2 分钟帮您把风险测评做了，匹配好您再决定，资料这就发您？"
- 打动一线：客户逼你要"准数"——说"保本"就违规，不说怕丢单。Jev 给出既合规又能推进成交的话术，这是普通 AI 回复工具做不到的。

**Case F2｜骗贷红线：客户要求造假（可做"炸场"演示）** 〔合规风控 · 隐私〕
- 客户说："我流水不够，能不能帮我包装个工作证明/做个假流水？中介都这么干。"
- Jev 判断：意图=要求协助骗贷 / 危险等级=**极高（9）** / 最佳动作=严词拒绝 + 说明法律后果 + 给正规增信路径。
- 候选示例："这个我真不能帮，做假流水属于骗贷，查出来不仅拒贷上黑名单，严重的要担法律责任。流水不够有正规办法——共同借款人、抵押担保，或选流水要求低的产品，我帮您看哪条走得通。"
- 打动一线：业绩压力下一句错话就能毁了职业生涯，Jev 永远替你踩住刹车。

**Case F3｜贷款用途违规（首付贷/炒股）** 〔合规风控=自保 · 专业话术〕
- 客户说："这笔消费贷我能不能拿去付房子首付？或者炒股？"
- Jev 判断：意图=试探资金违规用途 / 危险等级=**高（8）** / 最佳动作=明确拒绝违规用途 + 给合规替代，绝不顺着接。
- 候选示例："消费贷按规定不能用于购房首付或投资，这条我得跟您说清楚，不然对您征信和后续都有风险。如果是装修、购车、经营周转这类用途我可以帮您看额度；购房建议走正规房贷，我也能对接。您具体想解决哪块资金？"
- 打动一线：新人最容易被客户带偏说错话，一旦留痕就是合规隐患，Jev 每次先亮红灯。

**Case F4｜客户比价询价，抓住成交窗口** 〔转化 · 专业话术 · 知识沉淀〕
- 客户说："我想贷 30 万，你们利息多少？我私企上班月薪 1 万 2，房贷还没还清，能批吗？"
- Jev 判断：意图=询价+试探额度 / 危险等级=低 / **该马上回=是**（客户正在多家比价，窗口很短）/ 最佳动作=先给利率区间+准入条件、引导补资料，别把话说死。
- 候选方向：①给年化区间+基本条件、顺势要资料 ②先问清用途和负债再报价 ③直接约电话/线下深聊。
- 打动一线：比价客户回慢一步或回得不专业就跑了，秒级给出**能推进成交**的话术。

**Case F5｜逾期/情绪激动客户，防投诉升级** 〔合规风控 · 转化=挽留 · 专业话术〕
- 客户说："你们天天打电话烦不烦！我最近周转困难，再逼我就投诉你们！"
- Jev 判断：意图=情绪对抗+潜在投诉 / 危险等级=中高（舆情/投诉风险）/ 该马上回=是但要稳 / 最佳动作=先安抚、给协商方案（展期/分期），别硬催。
- 候选示例："实在抱歉给您添堵了，我理解您周转不容易。逾期不是只有催收一条路，我可以帮您申请展期或重新分期，把每月压力降下来，尽量不影响征信。您大概什么时候能缓过来？我按您情况报个能落地的方案。"
- 打动一线：催收沟通最容易出事，措辞不当就升级投诉，**既留住客户又保护你自己**。

**Case F6｜适当性错配：养老钱/跟风追高** 〔合规风控 · 专业话术 · 知识沉淀〕
- 客户说："我看隔壁老王买股票型基金赚了，我也要把养老钱全投进去。"
- Jev 判断：意图=跟风追高 / 危险等级=中高（适当性风险，养老钱 vs 激进产品错配）/ 最佳动作=提示风险测评匹配、做投教，别顺着卖。
- 候选示例："您这份心情我懂，但我得对您负责——股票型基金是 R4 高风险，得先和您风险测评结果匹配才能买。养老钱建议以稳为主，拿一小部分做权益、大头放稳健的。我先帮您做个测评，再配个让您睡得着觉的方案？"
- 打动一线：适当性错配（尤其老年客户）是**双录和监管检查的高频雷区**。

**Case F7｜行情下跌恐慌，防赎回+防投诉** 〔转化=挽留资产 · 专业话术 · 合规〕
- 客户说："今天又跌 3 个点！我基金亏两万了，是不是该割？你们怎么选的！"
- Jev 判断：意图=恐慌+质疑+潜在赎回 / 危险等级=中 / 该马上回=是（及时安抚）/ 最佳动作=先共情稳住、给理性视角、**绝不承诺回本**。
- 候选示例："看到账户缩水确实难受，我特别理解。但现在割在低点往往最亏——您这只主要持仓短期是市场情绪，基本面没变。长期闲钱可以拿住甚至逢低摊薄成本；短期要用我帮您重看配置。我拉个时间跟您把持仓过一遍？"
- 打动一线：一跌客户就要赎回+骂人，**回得专业就留住资产，回错就流失+投诉**。

**Case F8｜产品对比答疑，知识库保准确** 〔效率与知识沉淀 · 合规〕
- 客户说："你们这个和 XX 银行的差不多吧？费率、封闭期、起投都多少？"
- Jev 判断：意图=对比尽调 / 危险等级=低 / 最佳动作=**准确**给参数 + 差异化卖点。
- 关键展示：命中本地知识库里的真实产品资料（费率/封闭期/起投），面板顶部显示"知识库 N 条"命中，回复不瞎编。
- 打动一线：产品太多记不住，**报错数据就是合规问题**；知识库让新人也能秒答准。

### 演示动线（金融：惊艳 → 实用 → 安心）
1. **先炸场（F1 或 F2）**：让客户看到 Jev **先亮危险等级 + 识破真实意图**——立刻和普通"AI 帮你写回复"拉开差距。
2. **再秀实用（F4 + F8）**：3 条候选按"最合适"排序、一键填入，知识库命中报准参数——**帮我出单、帮我省事**。
3. **秀挽留（F5 或 F7）**：情绪客户/跌市安抚——**少踩雷、留住客户**。
4. **收尾讲底线**：只填不发、发送键永远你自己点、不碰转账红包收款、截图本机 OCR 不上传、密钥/知识库本地存储、可对接机构自有合规模型——给一线**安全感**，给合规/IT **兜底**。

## 附录 A：现场演示通用技巧（两个领域都适用）

- **提前把知识库配好**：至少放 2–3 条真实产品/款式资料并打好标签，演示时让面板顶部显示"知识库 N 条 · 历史 M 条"命中，最有说服力。
- **现场点"填入"但故意不点发送**：让一线亲眼看到"控制权在我手里"，这是打消顾虑的关键动作。
- **反复强调两个差异字段**：`危险等级（1–9）` 和 `对方真实意图`——这是 Jev 区别于所有"AI 帮你写回复"工具的核心。
