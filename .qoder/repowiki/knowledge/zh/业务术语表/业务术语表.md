### 悬浮球
- 定义：Jev 聊天助手在聊天 App 界面上显示的浮动按钮（overlay），长按弹出菜单（截屏识别一次、存为联系人等），点击后展开分析面板显示意图、危险等级和 3 条候选回复。它是用户触发分析和回填回复的主要入口。
- 别名：悬浮窗、overlay

### 判断接口
- 定义：Jev 聊天助手的三路接口之一，负责分析对方真实意图、危险等级（1–9）、是否该立即回复等决策问题，返回结构化 choices/scores，不生成自然语言文本。对应 Jev decisions 协议（`/alpha/decisions` 或 `/v1/systemone`），与通用的 chat/completions 接口不同。
- 别名：judge、意图判断

### 回复接口
- 定义：Jev 聊天助手的三路接口之一，负责根据判断结果和上下文起草 3 条口语化候选回复，采用 OpenAI 兼容 `chat/completions` 协议。默认使用智谱 GLM，可替换为 OpenRouter / DeepSeek / 通义等。
- 别名：reply、候选回复

### 视觉接口
- 定义：Jev 聊天助手的三路接口之一，用于 OCR 场景下的视觉理解（如截图后让模型看图），同样走 OpenAI 兼容 chat/completions 协议，可复用回复接口的 Base URL 和密钥。
- 别名：vision

### 测试判断
- 定义：设置页提供的连通性测试按钮，调用判断接口并期望返回具体意图名（而非占位的 `?`），用于验证判断接口的 Base URL、模型和 API Key 是否正确。
- 别名：judge test

### 测试回复
- 定义：设置页提供的连通性测试按钮，调用回复接口 ping 模型，期望返回「收到」两个字，用于验证回复接口的 Base URL、模型和 API Key 是否正确。
- 别名：reply test

### 截屏识别一次
- 定义：悬浮球菜单中的手动触发项，对当前屏幕执行截屏 + ML Kit 中文 OCR，将识别出的文字作为「对方所说」送入判断+回复链路。适用于未适配的 App 或微信树节点不可读的兜底场景。
- 别名：手动截屏、manual capture

### OCR 模式自动分析
- 定义：设置 → OCR 中的一个开关（`ocrAutoAnalyze`），默认关闭。打开后，当适配器返回空消息列表（即树里没正文但仍在聊天窗）时自动走截屏 + OCR 路径进行分析，无需手动触发。
- 别名：ocrAutoAnalyze

### 伪装服务
- 定义：绕过微信无障碍节点混淆的方案：将本项目的无障碍服务类名注册为系统内置的 `com.google.android.accessibility.selecttospeak.SelectToSpeakService`，从而能读取微信聊天界面的完整节点树。在 HyperOS 上截屏能力可能受限。
- 别名：SelectToSpeakService、伪装类名

### 防截屏风控
- 定义：微信对部分账号/设备开启的防护机制，会拒绝无障碍服务的 `takeScreenshot()` 调用（返回 FLAG_SECURE 错误码 6），导致 OCR 兜底失效。这是 v1.4 最初停用微信的原因，恢复后由使用者自担风险。
- 别名：FLAG_SECURE、微信风控

### 气泡 id
- 定义：聊天 App 中每条消息气泡的无障碍节点 resource-id，用于适配器从无障碍树中定位消息正文。例如微信是 `com.tencent.mm:id/bkl`，QQ 是 `com.tencent.mobileqq:id/mjn`。微信升级后 id 可能被混淆变化，需要更新。
- 别名：BUBBLE_ID、bubble_content_container

### debug 包
- 定义：使用 Android Debug 签名构建的 APK，`application-debuggable=true`，允许 adb shell run-as 读取应用私有目录（包括明文存储的 API Key 和知识库数据），适合临时验证但不适合长期主力安装。与 release 包签名不同，覆盖安装需先卸载。
- 别名：debug build、调试包

### release 包
- 定义：使用仓库外 keystore 签名的正式 APK，不可调试，体积更小（~25.8 MB vs debug ~28.2 MB），是面向用户的分发产物。当前版本 v1.4，versionCode=5，仅支持 ARM64。
- 别名：release build、正式版
