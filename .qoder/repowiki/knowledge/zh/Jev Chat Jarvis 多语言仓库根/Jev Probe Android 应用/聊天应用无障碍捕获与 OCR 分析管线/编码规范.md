- 对 AccessibilityNodeInfo 的遍历统一采用 `ArrayDeque` 栈 + `guard++` 上限（5000/6000）防止无限递归，并在循环中同时收集 viewIdResourceName、bounds、text 等元信息。
- 跨进程/跨版本资源 id 匹配一律使用 `viewIdResourceName` 字符串比较，而非反射或硬编码 class，便于 app 更新后通过日志中的 idInventory 定位新 id。
- 所有可能改变 UI 的回调（OCR 结果、Jev 判断、输入填充完成）都通过 `main.post` 切回主线程，调用方不再承担线程切换责任。
- 长任务提交统一包裹 `try { worker.execute(task) } catch (_: RejectedExecutionException) {}`，服务销毁后的废弃任务静默丢弃而不崩溃进程。
- 会话有效性检查在每个关键分支前重复调用 `isLive(manual, token)`，确保即使后台发生对话切换也不会把旧结果写进错误窗口。
