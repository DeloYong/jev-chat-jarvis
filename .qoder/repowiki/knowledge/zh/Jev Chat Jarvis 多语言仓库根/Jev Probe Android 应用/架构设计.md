所有子模块以 Kotlin 包形式内聚于 app/src/main/java/com/jev/probe 下，通过包级依赖而非独立 Gradle 模块协作：
- capture_ocr_pipeline（capture/）作为前台服务入口，监听 AccessibilityService 并调用 jev_api_clients（jev/）发起判断/回复请求；当树不可读时回退到同包的 ML Kit OCR。
- knowledge_base_core（core/kb/）被 capture 与 UI 共享，提供 KbStore/KbModels 等本地数据源，并通过 core/Prefs.kt 访问 SharedPreferences。
- ui_and_overlay（overlay/ + MainActivity/KnowledgeActivity/SettingsActivity）负责悬浮窗展示与权限引导，读取 core/ 中的知识库状态。
- 三者通过 AndroidManifest.xml 统一注册：MainActivity 为 LAUNCHER，SelectToSpeakService 绑定 accessibilityservice 配置，KeepAliveService 以 FOREGROUND_SERVICE_SPECIAL_USE 保活；所有组件共享 applicationId com.jev.probe、Theme.JevProbe 与同一套 strings/themes。
- build.gradle.kts 集中声明 minSdk 30 / targetSdk 35 / Java 17，仅保留 arm64-v8a ABI 以裁剪 ML Kit 原生库体积，并使用 JEV_KEYSTORE_PROPS 环境变量注入签名信息。
