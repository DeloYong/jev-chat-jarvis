模块按职责拆分为两个层次：
- `core` 根包：`ChatModels.kt` 定义跨层共享的快照/消息/分析结果数据结构（`Msg`、`BubbleRect`、`ChatSnapshot`、`Analysis`），`Prefs.kt` 封装所有 SharedPreferences 读写，集中管理 judge/reply/vision 三条 API 路由、OCR 开关、对话白名单等配置，并提供迁移逻辑（v1.2→v1.3）和默认值注入。
- `core/kb` 子包：围绕 `KbStore` 单例实现基于 `filesDir/kb/*.json` 的手写 JSON 存储，承载三类实体——`Note`（自由文本知识）、`Contact`（跨应用联系人及别名）、`LogEntry`（每联系人 ≤300 行的历史）。`ContextBuilder` 是唯一的消费入口，根据当前 `ChatSnapshot` 匹配联系人、检索历史并筛选命中笔记，按 `BUDGET_CHARS=1500` 预算裁剪后产出 `ChatContext`；`KbSelfCheck` 通过临时 Prefs + 真实 KbStore 运行自检用例。
依赖方向单向：`ContextBuilder` → `KbStore`，`KbSelfCheck` → `ContextBuilder` + `KbStore`，二者都只读 `ChatModels` 与 `Prefs`；`KbStore` 不反向依赖上层。
