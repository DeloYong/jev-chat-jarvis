- 所有对 `KbStore` 的读写方法都用 `synchronized(lock)` 包裹，并通过 `writeAtomic`（先写 `.tmp` 再 `renameTo`）保证崩溃不留下半截 JSON。
- JSON 文件损坏时不会直接覆盖：尝试将原文件重命名为 `<name>.corrupt.<timestamp>`，仅当备份成功才清空缓存，否则加入 `unreadable` 集合拒绝后续写入。
- 模型类统一采用 Kotlin data class，并在 `updatedAt` 字段上记录 `System.currentTimeMillis()`，用于排序与展示。
- 敏感键名以 `K_` 前缀常量集中在 `Prefs` companion object 中声明，getter/setter 一律调用 `sp.edit().putXxx(...).apply()`，日志只记录键长度而非值。
- 对外暴露的静态工具（如 `normalizeName`、`displayName`、`newId`）放在 `KbStore.companion object` 中，避免在类加载期执行可能失败的正则编译。
- 测试/自检代码通过传入自定义 `prefsName` 构造独立的 `Prefs` 实例，隔离用户真实配置，并在 finally 块中清理临时数据。
