模块由三部分组成：
- `overlay/OverlayController.kt`：独立的悬浮窗控制器，通过 `WindowManager.LayoutParams.TYPE_APPLICATION_OVERLAY` 创建不可聚焦的顶层窗口，内部维护 bubble（可拖拽入口）、panel（半透明分析面板）和菜单；通过 `onManualAnalyze` / `onSaveContact` / `onOcrCapture` / `onFill` 等 lambda 回调与上层 capture 服务解耦，仅消费 `core.Analysis`、`core.RankedReply`、`core.ChatSnapshot` 等数据模型。
- `MainActivity.kt`：应用启动后的首页，以纯代码构建卡片式布局，检查无障碍、悬浮窗、密钥三项就绪状态并引导用户跳转系统设置开启。
- `Insets.kt`：为 targetSdk 35 + Android 15+ edge-to-edge 行为提供 `View.padForSystemBars()` 扩展，被 MainActivity、SettingsActivity、KnowledgeActivity 复用。
依赖方向单向向外：UI 层只读 `com.jev.probe.core.*` 中的模型与 `Prefs`，不反向依赖 capture/jev 子包；悬浮窗通过 `Intent.setClassName("com.jev.probe.SettingsActivity")` 直接启动同进程 Activity，避免跨组件通信。
