- 所有尺寸统一通过 `dp(v)` 工具方法（`TypedValue.applyDimension(COMPLEX_UNIT_DIP, ...)`）换算，避免硬编码像素值。
- 圆角背景统一封装为 `card(radius, color, stroke)` 或 `roundBg(radius, color)`，通过 `GradientDrawable` 设置圆角与描边。
- 对外部调用（如 `wm.addView`、`startActivity`、网络请求）用 `runCatching { ... }` 包裹，失败时记录日志或 toast，不向上抛出异常。
- UI 文案与颜色常量集中在 `companion object` 中集中声明（如 `INTENT`/`NEEDS`/`ACTION` 映射表、`PRIVACY_URL`）。
