- 所有对外 HTTP 调用通过 `HttpJson.post` 发起，并传入 `Route.JUDGE`/`REPLY`/`VISION` 常量作为错误来源标识，禁止直接构造 HttpURLConnection。
- HTTP 2xx 响应体必须经 `ResponseShape.ok` / `chatContent` / `jevAnswers` / `threeCandidates` 解析后再返回，禁止直接使用原始 `JSONObject`，以保证 200+error 体和空内容被转为 `ApiException`。
- 每个客户端类仅持有 `Prefs` 一个依赖，endpoint/key/model 均在方法内从 `Prefs` 读取，使切换提供商无需重建客户端实例。
- 对上游可能返回 4xx 的新字段（如 judge 的 background/history）采用“先带字段发送，失败后降级不带字段重试一次”的防御式回退模式。
- 面向用户的错误消息由 `describe` 与 `ApiException.buildMessage` 集中生成中文文案，原始异常信息中不包含 key 等敏感内容。
