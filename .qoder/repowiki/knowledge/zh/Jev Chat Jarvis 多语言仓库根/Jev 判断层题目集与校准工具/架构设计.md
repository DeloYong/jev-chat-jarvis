模块按职责拆分为四层：
- HTTP 客户端层 `jev_client.py`：仅用标准库 `urllib` 实现 `ask(state, questions)`，从环境变量 `OPENROUTER_API_KEY` 读取密钥，对 429/529 做指数退避重试（最多 3 次），并通过 `redact_secrets` 在日志/错误输出中脱敏 key。
- 题目定义层 `questions.py`：集中声明 `JUDGE_QUESTIONS`（literal_question/true_intent/danger_level/should_reply_now/best_action/she_needs/tension_resolved）以及 `build_state`、`build_rank_question` 等构造器，约定 instructions/criteria 一律英文、state 内聊天原文保留中文。
- 数据层 `fixtures/labeled_set.json`：≥25 条人工标注的对话片段，每条含 id、relationship、messages、expect（true_intent/score/she_needs/tension_resolved）。
- 运行与报告层 `calibrate.py`：串行遍历标注集，每例间隔 0.3s，计算命中率、danger_level MAE、平均置信度、延迟与总花费，输出 `report/calibration.json` 与 `report/calibration.md`，并通过 gates 判定是否达标（MAE<1.0、true_intent/she_needs ≥60%）。
- 辅助脚本 `demo_meme.py`、`probe_background_field.py` 作为交互式入口，复用上述三层。
依赖方向单向：calibrate/demo/probe → questions → jev_client；不反向依赖 app 或 gradle。
