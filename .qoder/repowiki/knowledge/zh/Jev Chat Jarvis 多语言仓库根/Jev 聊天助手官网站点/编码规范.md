- 所有用户可见文案集中写在 `i18n.js` 的 `window.JEV_I18N.zh` / `.en` 字典中，HTML 通过 `data-i18n` 或 `data-i18n-attr="attr:key"` 引用键值，JS 侧通过 `t("key")` 读取。
- 运行时语言切换由 `main.js` 的 `applyLang` 统一驱动，更新 `documentElement.lang`、`[data-i18n]` 的 innerHTML 与 `[data-i18n-attr]` 的属性值，并通过 `onLang` 回调通知各子系统刷新。
- 构建与校验脚本使用 Node ESM（`import.meta.url` + `fileURLToPath`）定位仓库根，并以相对路径读写 `content/`、`guides/`、`index.html` 等文件。
- 教程页面模板在 `build-guides.mjs` 中以字符串模板生成，对标题、描述等用户输入一律经 `esc()` 转义后再写入 HTML。
- 对外链接统一指向 `https://github.com/jev-chat/jev-chat-jarvis`，不携带 README 锚点，保证无 JS 时也可跳转。
