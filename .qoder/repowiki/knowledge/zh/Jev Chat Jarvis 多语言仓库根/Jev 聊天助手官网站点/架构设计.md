站点由纯静态 HTML + CSS + 原生 JS 组成，无构建框架：
- 入口文件 `index.html` / `en.html` / `privacy.html` 共享 `style.css`、`guide.css`、`main.js` 与 `i18n.js`；`main.js` 通过 `window.JEV_I18N` 实现运行时中英切换（`data-i18n` / `data-i18n-attr`），并处理主题、导航、首屏演示动画、复制与 GitHub Star 数。
- 文案单一来源在 `i18n.js`，中文正文由 `tools/check-i18n.mjs --fix` 同步写回 `index.html`，同时校验键一致性、孤儿键、重复键与中英文对齐。
- 教程内容以 `content/guides.json` 为数据源，由 `tools/build-guides.mjs` 生成 `guides/*.html` 单页（含 SEO、BreadcrumbList JSON-LD、hreflang）；`tools/build-discovery.mjs`、`tools/submit-indexnow.mjs` 负责搜索引擎发现，`tools/check-i18n.mjs` 也复用其 HTML 扫描器。
- 资源集中在 `assets/`（favicon、og.png、二维码等），SEO 元信息（sitemap.xml、robots.txt、llms.txt、indexnow-key.txt）位于根目录。
- 设计说明见 `DESIGN.md`，维护流程见 `MAINTAINING.md`。
