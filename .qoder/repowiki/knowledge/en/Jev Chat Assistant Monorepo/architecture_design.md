Flat multi-project layout: `settings.gradle.kts` declares only the root Gradle project and includes the Android subproject (`:app`); the Python tooling lives in `tools/` and the docs site in `site/`, both outside Gradle's build graph. Cross-child wiring is by directory convention rather than build-time dependency — the Android app consumes the Jev assistant HTTP API documented in `docs/`, while the Python tooling calls the same OpenRouter decisions endpoint used at runtime. Shared repository concerns (Gradle plugin versions, Kotlin/AndroidX flags, JVM args) are centralized in the root `build.gradle.kts` and `gradle.properties`; child modules do not share code or artifacts across languages.
